How the implied value is worked out

Implied value = TVL × category multiple × growth × age × launch plausibility.

  • Category multiple — the median market-cap per TVL dollar of the protocols in the same category whose token already trades, shrunk toward the global median when a category has few live comps. The market prices a unit of TVL; the model borrows that price.
  • Growth — the protocol's 7-day TVL change, clamped to −60%…+150%, worth 0.76×…1.60×. A week of fast growth is momentum; a collapse is a warning.
  • Age — how long DefiLlama has tracked the protocol: 0.70× for a fresh listing, rising to 1.00× at four years. Older means a record to judge.
  • Launch plausibility — the snapshot's own watchlist rule: 1.00× when it passes, 0.60× for a versioned deployment, 0.50× for a bridge or liquid-staking product, 0.30× for a centralised exchange, 0.25× for a wrapped or staked product of a token that already trades.

No protocol name is hardcoded anywhere in the model. Every figure comes from the sealed snapshot (DefiLlama, fetched 2026-11-14). An implied value is this entry's own claim about what a launch would be worth if the protocol's record stayed as it is — it is not a prediction that a token will be issued, or when.

“Records no token” means DefiLlama's record carries no token for the protocol, not that it has none: a protocol on the board may still have a token its record does not carry. Farm steps are a reader's plan, not financial advice — never deposit more than you can afford to lose.
